## Monomials: Definition and Example Definition
A monomial is a mathematical expression in algebra that consists of a single term. It is a product of non-negative integer powers of variables. A monomial can be represented using a multi-index notation, which provides a compact way to handle the powers of variables in multivariable functions.

Given a vector of variables $x = [x_1,x_2,...,x_n]^{\top} \in \mathbb{R}^{n}$,  and a multi-index  $\nu = [\nu_1,\nu_2,...,\nu_n]^{\top} \in \mathbb{N}^{n}$, a monomial can be expressed as:
$x^{\nu} = x_1^{\nu_1}x_2^{\nu_2}...x_n^{\nu_n}$

##### General Example:
Consider the vector $x=[x_1,x_2]$ and the multi-index $\nu=[2,2]$. Using the multi-index notation, we can list all possible monomials generated by varying the exponents up to the specified values in $\nu$:

$ν=(0,0): x^{\nu} = x_1^0⋅x_2^0 =1$

$ν=(0,1): x^{\nu} = x_1^0⋅x_2^1 = x_2$

$ν=(0,2): x^{\nu} = x_1^0⋅x_2^2 = x_2^2$

$ν=(1,0): x^{\nu} = x_1^1⋅x_2^0= x_1$

$ν=(1,1): x^{\nu} = x_1^1⋅x_2^1 = x_1. x_2$

$ν=(1,2): x^{\nu} = x_1^1⋅x_2^2 = x_1.x_2^2$

$ν=(2,0): x^{\nu} = x_1^2⋅x_2^0 = x_1^2$

$ν=(2,1): x^{\nu} = x_1^2⋅x_2^1 = x_1.x_2$

$ν=(2,2): x^{\nu} = x_1^2⋅x_2^2 = x_1^2.x_2^2$

When the maximum degree of monomials is limited to $d$, i.e., $|\nu|:=\Sigma_{i=1}^n \nu_i$,  and
$(x^{\nu})_{|\nu|\leq d} =\bigg( 1, x_1, x_2, x_1.x_2, x_1^2, x_2^2 \bigg) $. To list

$ν=(0,0): x^{\nu} = x_1^0⋅x_2^0 =1$

$ν=(1,0): x^{\nu} = x_1^1⋅x_2^0= x_1$

$ν=(0,1): x^{\nu} = x_1^0⋅x_2^1 = x_2$

$ν=(1,1): x^{\nu} = x_1^1⋅x_2^1 = x_1. x_2$

$ν=(2,0): x^{\nu} = x_1^2⋅x_2^0 = x_1^2$

$ν=(0,2): x^{\nu} = x_1^0⋅x_2^2 = x_2^2$

These monomials form the canonical basis of the vector space $\mathbb{R}[x]_d$ of polynomials of degree at most $d$.

##### Numerical Example:
Consider the vector $x=[5,6]$ and the multi-index $\nu=[3,2]$. Using the multi-index notation, we can list all possible monomials generated by varying the exponents up to the specified values in $\nu$:

$ν=(0,0): x^{\nu} = 5^0⋅6^0 = 1$

$ν=(0,1): x^{\nu} = 5^0⋅6^1 = 6$

$ν=(0,2): x^{\nu} = 5^0⋅6^2 = 36$

$ν=(1,0): x^{\nu} = 5^1⋅6^0 = 5$

$ν=(1,1): x^{\nu} = 5^1⋅6^1 = 30$

$ν=(1,2): x^{\nu} = 5^1⋅6^2 = 180$

$ν=(2,0): x^{\nu} = 5^2⋅6^0 = 25$

$ν=(2,1): x^{\nu} = 5^2⋅6^1 = 150$

$ν=(2,2): x^{\nu} = 5^2⋅6^2 = 900$

$ν=(3,0): x^{\nu} = 5^3⋅6^0 = 125$

$ν=(3,1): x^{\nu} = 5^3⋅6^1 = 750$

$ν=(3,2): x^{\nu} = 5^3⋅6^2 = 4500$


## Positive Polynomials

#### One-Dimensional Case

For any real polynomial $p(x)$ in one variable $x$, if $p(x) \geq 0$ for all $x \in \mathbb{R}$, then $p(x)$ can be expressed as a sum of squares of other polynomials. Mathematically, if $p(x) \geq 0$, then there exists a finite set of polynomials $\{h_i(x)\}$ such that $p(x) = \Sigma_{i=1}^k h_i(x)^2$.

Consider the polynomial  $p(x) = x^2+2x+1$. This polynomial is nonnegative for all $p(x)=(x+1)^2$, which is clearly a sum of squares (in this case, just one square).

#### Multi-Dimensional Case
A classic example of a polynomial that is nonnegative but not a sum of squares is Motzkin's polynomial in two variables, given by $p(x,y) = x^4y^2+x^2y^4-3x^2y^2+1$. For all $(x,y) \in \mathbb{R}^2, p(x,y) \geq 0$, yet it cannot be represented as a sum of squares of polynomials. However, according to Artin's solution to Hilbert's 17th problem, it can be expressed as a sum of squares of rational functions.
